My Project Idea

ISET Interactive Campus Map

Helping new students discover and navigate the ISET Nabeul campus more easily.

Status: Concept – In Progress

01. Project Overview

The ISET Interactive Campus Map is a project idea designed to help new students find classrooms, departments and important services inside ISET Nabeul.

02. The Problem

New students may have difficulty finding classrooms, offices and different campus facilities, especially during their first days at university.

03. Proposed Solution

I propose creating an interactive digital map that allows students to explore the campus and find useful locations more easily.

04. Planned Features

Interactive Map

Explore different areas of the campus through a visual map.

Location Search

Search for classrooms, departments and university services.

3D Visualization

Explore the campus through a possible 3D representation.

05. Planned Technologies

HTML – Website structure
CSS – Design and layout
JavaScript – Interactivity

A 3D library may be considered during a future development stage.

06. Learning Objectives

This project will help me improve my web development skills, learn interactive design and explore new technologies.

07. Project Status

Current stage: Project concept and planning. Implementation and testing are future steps.
