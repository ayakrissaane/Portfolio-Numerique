What is Computer Architecture?

Computer Architecture describes the organization and operation of a computer system. It explains how hardware components work together to process, store and transfer information.

Main Computer Components

🧠

CPU

The Central Processing Unit executes instructions and processes data.

💾

RAM

Random Access Memory temporarily stores data used by running programs.

📀

ROM

Read-Only Memory stores information that is generally retained without power.

⌨️

Input Devices

Devices such as keyboards and mice allow users to enter data.

🖥️

Output Devices

Devices such as monitors and printers present processed information.

Digital Electronics

Digital Electronics is based on binary values: 0 and 1. Digital circuits use logical operations to process information.

Logic Gates

AND

AND Gate

The output is 1 only when all inputs are 1.

OR

OR Gate

The output is 1 when at least one input is 1.

NOT

NOT Gate

The output is the opposite of the input.
