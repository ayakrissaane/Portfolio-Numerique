Prompt Engineering

Apprendre à formuler des demandes précises et à évaluer les réponses des outils d’intelligence artificielle.

01. Qu’est-ce qu’un prompt ?

Un prompt est une instruction ou une question donnée à un outil d’intelligence artificielle. Un prompt clair précise le contexte, l’objectif, les contraintes et le format attendu.

02. Structure d’un bon prompt

Contexte

Présenter la situation et les informations utiles.

Objectif

Expliquer exactement ce que l’on souhaite obtenir.

Format

Indiquer la forme souhaitée : tableau, étapes, résumé ou exemple.

03. Exemple de prompt

Explique la boucle FOR en langage C à un débutant.

Utilise des mots simples, un exemple court,
puis propose un exercice sans donner immédiatement la solution.

04. Vérifier les réponses

  • Vérifier les faits et les exemples.
  • Tester le code avant de l’utiliser.
  • Repérer les informations inventées ou imprécises.
  • Ne pas transmettre de données privées.
  • Garder une trace des prompts importants utilisés dans le projet.

05. Transparence de l’IA

Outil : ChatGPT, pour expliquer les principes et améliorer la formulation.

Rôle : proposer des exemples et aider à structurer la fiche.

Ma contribution : choisir les objectifs, tester les prompts et vérifier les réponses.

Vérification : comparer les résultats avec le cours et des sources fiables.
