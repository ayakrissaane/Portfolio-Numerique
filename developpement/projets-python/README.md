
# Mini Calculator

## 1. Description du projet
Mini Calculator est un programme simple développé en Python.
Il permet à l'utilisateur d'effectuer quatre opérations :
addition, soustraction, multiplication et division.

## 2. Fonctionnalités
- Addition
- Soustraction
- Multiplication
- Division
- Vérification de la division par zéro
- Vérification de l'opération choisie

## 3. Outil utilisé
- Visual Studio Code
- Python

## 4. Concepts Python utilisés
- Variables
- input()
- print()
- float()
- Conditions : if, elif, else
