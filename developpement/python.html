Programmation en Python

Découvrir les premières notions de Python à travers des exemples simples.

01. Présentation

Python est un langage de programmation reconnu pour sa syntaxe lisible. Il peut être utilisé dans le développement, l’automatisation, l’analyse de données et l’intelligence artificielle.

02. Premières notions

Variables

Créer des variables pour conserver des valeurs.

Conditions

Utiliser if et else pour contrôler le programme.

Boucles

Répéter des instructions avec for et while.

03. Exemple : calculer une moyenne

note1 = float(input("Première note : "))
note2 = float(input("Deuxième note : "))

moyenne = (note1 + note2) / 2

print("Moyenne :", moyenne)
