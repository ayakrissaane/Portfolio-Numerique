01 — THE FUNDAMENTALS

What is Algorithmique?

Algorithmics is the process of designing a clear, logical sequence of instructions to solve a problem. Before writing code, we first understand the problem and organise the solution into steps.

⌕

Understand

Identify the problem, the input data and the expected result.

↗

Design

Organise the solution into simple, logical and ordered instructions.

♡

Implement

Translate the algorithm into a programming language and test the result.

ALGORITHM 01

Recherche du maximum

Finding the largest value in an array of integers.

Arrays · Loops · Conditions
Idée générale : We suppose that the first element is the maximum. Then, we compare it with every other element. If we find a greater value, we update the maximum.

01. Pseudo-code

Algorithme Recherche_Maximum
Variables
    T : tableau d'entiers
    n, i, max : entier
Début
    Lire(n)

    Pour i ← 0 à n-1 faire
        Lire(T[i])
    FinPour

    max ← T[0]

    Pour i ← 1 à n-1 faire
        Si T[i] > max Alors
            max ← T[i]
        FinSi
    FinPour

    Écrire(max)
Fin

02. Exemple pas à pas

Let's consider the array: [4, 9, 2, 7]

Step Value Current maximum Action
Initial 4 4 Initialisation
1 9 9 9 > 4, update
2 2 9 2 < 9, no change
3 7 9 7 < 9, no change
Result Maximum = 9

03. Traduction en langage C

maximum.c C LANGUAGE 
#include <stdio.h>

int main()
{
    int T[100], n, i, max;

    printf("Enter the size of the array: ");
    scanf("%d", &n);

    while (n < 1 || n > 100)
    {
        printf("Enter a size between 1 and 100: ");
        scanf("%d", &n);
    }

    for (i = 0; i < n; i++)
    {
        printf("T[%d] = ", i);
        scanf("%d", &T[i]);
    }

    max = T[0];

    for (i = 1; i < n; i++)
    {
        if (T[i] > max)
        {
            max = T[i];
        }
    }

    printf("Maximum = %d\n", max);

    return 0;
}
ALGORITHM 02

Tri par sélection

Sorting an array in ascending order using Selection Sort.

Arrays · Nested Loops · Swap
Idée générale : At each pass, we search for the smallest element in the unsorted part of the array. We then exchange it with the first element of that part.

01. Pseudo-code

Algorithme Tri_Selection
Variables
    T : tableau d'entiers
    n, i, j, indiceMin, temp : entier
Début
    Pour i ← 0 à n-2 faire
        indiceMin ← i

        Pour j ← i+1 à n-1 faire
            Si T[j] < T[indiceMin] Alors
                indiceMin ← j
            FinSi
        FinPour

        temp ← T[i]
        T[i] ← T[indiceMin]
        T[indiceMin] ← temp
    FinPour

    Écrire(T)
Fin

02. Exemple pas à pas

Initial array: [7, 3, 5, 2]

Pass Smallest value Exchange Array after pass
Initial — — [7, 3, 5, 2]
1 2 7 ↔ 2 [2, 3, 5, 7]
2 3 No exchange [2, 3, 5, 7]
3 5 No exchange [2, 3, 5, 7]
Result [2, 3, 5, 7]

03. Traduction en langage C

selection_sort.c C LANGUAGE 
#include <stdio.h>

int main()
{
    int T[100], n, i, j;
    int indiceMin, temp;

    printf("Enter the size of the array: ");
    scanf("%d", &n);

    while (n < 1 || n > 100)
    {
        printf("Enter a size between 1 and 100: ");
        scanf("%d", &n);
    }

    for (i = 0; i < n; i++)
    {
        printf("T[%d] = ", i);
        scanf("%d", &T[i]);
    }

    for (i = 0; i < n - 1; i++)
    {
        indiceMin = i;

        for (j = i + 1; j < n; j++)
        {
            if (T[j] < T[indiceMin])
            {
                indiceMin = j;
            }
        }

        temp = T[i];
        T[i] = T[indiceMin];
        T[indiceMin] = temp;
    }

    printf("Sorted array: ");

    for (i = 0; i < n; i++)
    {
        printf("%d ", T[i]);
    }

    return 0;
}
ALGORITHM 03

Recherche séquentielle

Searching for a specific value inside an array.

Arrays · Loops · Conditions
Idée générale : We examine the elements one by one, starting from the beginning of the array. If the searched value is found, we stop and display its position. Otherwise, we continue until the end of the array.

01. Pseudo-code

Algorithme Recherche_Sequentielle
Variables
    T : tableau d'entiers
    n, i, x, position : entier
Début
    Lire(n)

    Pour i ← 0 à n-1 faire
        Lire(T[i])
    FinPour

    Lire(x)
    position ← -1
    i ← 0

    TantQue i < n ET position = -1 faire
        Si T[i] = x Alors
            position ← i
        Sinon
            i ← i + 1
        FinSi
    FinTantQue

    Si position = -1 Alors
        Écrire("Not found")
    Sinon
        Écrire(position)
    FinSi
Fin

02. Exemple pas à pas

Array: [8, 3, 6, 2, 9] — Value to search: 6

Index Value Comparison Result
0 8 8 ≠ 6 Continue
1 3 3 ≠ 6 Continue
2 6 6 = 6 Found!
Result Element found at index 2 (position 3)

03. Traduction en langage C

linear_search.c C LANGUAGE 
#include <stdio.h>

int main()
{
    int T[100], n, i, x;
    int position = -1;

    printf("Enter the size of the array: ");
    scanf("%d", &n);

    while (n < 1 || n > 100)
    {
        printf("Enter a size between 1 and 100: ");
        scanf("%d", &n);
    }

    for (i = 0; i < n; i++)
    {
        printf("T[%d] = ", i);
        scanf("%d", &T[i]);
    }

    printf("Enter the value to search: ");
    scanf("%d", &x);

    for (i = 0; i < n && position == -1; i++)
    {
        if (T[i] == x)
        {
            position = i;
        }
    }

    if (position == -1)
    {
        printf("Element not found.\n");
    }
    else
    {
        printf("Element found at position %d\n", position + 1);
    }

    return 0;
}
