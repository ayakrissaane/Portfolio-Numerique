What is an Algorithm?

An algorithm is a sequence of clear and organized instructions used to solve a specific problem. It describes the steps needed to obtain a result.

Main Concepts

📦

Variables

Variables are used to store values such as integers, real numbers and characters.

🔀

Conditions

Conditions allow an algorithm to make decisions using Si, Sinon and Selon.

🔁

Loops

Loops repeat instructions using Pour, Tant que and Répéter.

📚

Arrays

Arrays store several values of the same type and allow us to process them.

🧩

Problem Solving

Analyzing a problem and organizing the steps needed to solve it.

Practical Example

Finding the Maximum of Two Numbers

This algorithm reads two numbers and displays the greatest one. 

Algorithme Maximum

Variables
    A, B : entier

Début
    Ecrire("Donner deux nombres :")
    Lire(A, B)

    Si A > B Alors
        Ecrire(A)
    Sinon
        Ecrire(B)
