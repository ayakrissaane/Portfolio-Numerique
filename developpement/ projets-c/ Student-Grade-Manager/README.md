
# Student Grade Manager

## Description
A simple C application that allows users
to enter student grades and calculate
their average.

## Features
- Enter the number of grades.
- Store grades in an array.
- Calculate the average.
- Display the final result.
- Check whether the student passed or failed.

## Concepts Used
- Variables
- Conditions
- Loops
- Arrays
- Functions

## Development Tool
Code::Blocks

## Testing
The program was tested with different
grades to verify the average and result.
