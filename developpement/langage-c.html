Programmation en langage C

Présenter les bases du langage C et les exercices pratiques réalisés pendant l’apprentissage.

01. Présentation

Le langage C est un langage de programmation compilé, utilisé notamment pour apprendre les bases de la programmation et comprendre le fonctionnement des programmes.

02. Notions de base

Variables

Stocker une valeur dans un type adapté : int, float, char.

Conditions

Utiliser if, else et switch pour choisir une action.

Boucles

Répéter des instructions avec for, while et do while.

03. Exemple : calculer une somme

#include <stdio.h>

int main() {

    int a, b, somme;

    printf("Donner deux nombres : ");
    scanf("%d %d", &a, &b);

    somme = a + b;

    printf("Somme = %d", somme);

    return 0;
}

Cet exemple illustre la déclaration de variables, la lecture avec scanf et l’affichage avec printf.
