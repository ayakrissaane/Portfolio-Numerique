03 — UNDERSTANDING LANGUAGES

Python vs C

Two programming languages, different approaches to solving problems.

Py Python
VS
C Language C
Criteria Python C
Syntax Simple and readable syntax. More detailed syntax, with braces and semicolons.
Typing Dynamic typing: the type is determined during execution. Static typing: variables are declared with a type.
Memory management Mostly automatic memory management. More direct control over memory management.
Speed Generally slower in execution. Generally faster in execution.
Uses Web development, automation, data science and AI. System programming, embedded systems and performance-oriented software.

These are general differences. Actual performance and memory behaviour can depend on the program and its environment.
