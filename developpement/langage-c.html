Practical Example

Calculating the Sum of Two Numbers

This simple program asks the user to enter two integers and displays their sum. 

#include <stdio.h>

int main() {

    int a, b, somme;

    printf("Enter the first number: ");
    scanf("%d", &a);

    printf("Enter the second number: ");
    scanf("%d", &b);

    somme = a + b;

    printf("The sum is: %d", somme);

    return 0;
}
