Un site personnel pour présenter mon parcours, mes compétences et mes réalisations à l’ISET Nabeul.

Site en ligne

01. Présentation du projet

Ce portfolio est un site web personnel qui rassemble mon parcours universitaire, les notions étudiées, mes travaux pratiques et mes projets. Il évoluera au fil de ma formation.

02. Objectifs

Présenter

Organiser les compétences et les apprentissages.

Documenter

Conserver des traces de travaux réellement réalisés.

Progresser

Améliorer le contenu et le site au fil du temps.

03. Technologies utilisées

HTML CSS JavaScript GitHub GitHub Pages

HTML structure les pages, CSS définit leur apparence et JavaScript ajoute des interactions simples. GitHub Pages héberge le site.

04. Étapes de réalisation

  1. Créer un dépôt GitHub public.
  2. Organiser les fichiers et les dossiers.
  3. Créer la page d’accueil et les pages thématiques.
  4. Ajouter le style commun et les interactions.
  5. Tester les liens et l’affichage sur plusieurs écrans.

05. Transparence de l’IA

Outil : ChatGPT utilisé pour expliquer, structurer et relire certains éléments du code.

Rôle : assistant de développement et d’apprentissage.

Ma contribution : choisir l’organisation et le style, intégrer les fichiers, tester le site et être capable d’expliquer les éléments utilisés.

Vérification : tester les pages publiées, les liens relatifs et le rendu responsive.
